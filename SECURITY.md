# Reporting a security vulnerability

If you find a vulnerability in OpenFPL Scout AI or its hosted API, report it privately to [Islam Kassem by email](mailto:iqasem4444@gmail.com). Keep the details out of public issues and pull requests while the maintainer investigates.

Include the affected route or component, the version or commit if known, what you observed, and the potential impact. A minimal example helps the maintainer confirm the problem. Redact bearer tokens, API keys, and personal data from examples, logs, and screenshots before sending them.
